## 已有模块（不动）

| Package | 说明 |
|---------|------|
| `ar_description` | URDF 描述 + STL 模型 |
| `ar_hardware_interface` | ros2_control 硬件接口 + Teensy 串口驱动 |
| `ar_moveit_config` | MoveIt2 运动规划配置 |
| `ar_gazebo` | Gazebo 仿真启动 |

## 新增模块（待开发）

| Package | 文件数 | 预计行数 | 说明 |
|---------|:---:|------|------|
| `robot_interfaces` | 6 | ~25 | msg / srv / action 定义 |
| `task_control` | 9 | ~400 | TaskManager + MissionScheduler + MaterialManager |
| `robot_executor` | 5 | ~150 | MoveIt2 执行封装 |
| `bringup` | 3 | ~40 | 一键启动 |
