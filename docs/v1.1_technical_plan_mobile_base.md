# AR4 ROS2 v1.1 技术方案 — 移动底盘集成

## 一、系统架构

```
task_manager_node (入口)
    ↓
TaskManager (服务层) ←→ ROS2 Service
    ↓
MissionScheduler (调度层) → Step 序列构建 + 执行
    ↓                           ↓
RobotExecutor (执行层)    BaseExecutor (底盘执行层)
    ↑                           ↑
MaterialManager (数据层) ← YAML 配置
```

## 二、硬件布局

```
                    滑轨方向 (X轴)
    ←─────────────────────────────────────→

    任务区                              物料区
    ┌─────┐    ┌─────┐    ┌─────┐    ┌─────────────────────┐
    │     │    │     │    │     │    │  L3   L2   L1  R1  R2  R3  │
    │  T  │    │  T  │    │  T  │    │  ○    ○    ○   ○   ○   ○  │
    │     │    │     │    │     │    │                     │
    └─────┘    └─────┘    └─────┘    └─────────────────────┘
       ↑          ↑          ↑              ↑
    任务点     任务点     任务点         物料点 (固定)

    T = 任务台    L = Left    R = Right
```

## 三、任务流程设计

### Task 1 — 放任务 (任务区取料 → 物料区放置)

```
阶段1: 任务区取料 (机械臂)
1.  Home (关节)
2.  task_point_A (关节)
3.  task_point_A → task_pose (笛卡尔直线)
4.  task_pose (关节)
5.  task_pose → task_point_B (笛卡尔直线)
6.  task_point_B (关节)
7.  Home (关节)

阶段2: 底盘移动 (滑轨)
8.  任务区 → 物料区 (固定路径)

阶段3: 物料区放置 (机械臂)
9.  Home (关节)
10. na, nb (关节)
11. nb → material_pose (笛卡尔直线)
12. material_pose (关节)
13. material_pose → nc (笛卡尔直线)
14. nc (关节)
15. Home (关节)

总计: 15 步
```

### Task 2 — 取任务 (镜像)

```
阶段1: 物料区取料 (机械臂)
1.  Home (关节)
2.  nc (关节)
3.  nc → material_pose (笛卡尔直线)
4.  material_pose (关节)
5.  material_pose → nb (笛卡尔直线)
6.  nb → na (关节)
7.  Home (关节)

阶段2: 底盘移动 (滑轨)
8.  物料区 → 任务区 (固定路径)

阶段3: 任务区放置 (机械臂)
9.  Home (关节)
10. task_point_B (关节)
11. task_point_B → task_pose (笛卡尔直线，反转)
12. task_pose (关节)
13. task_pose → task_point_A (笛卡尔直线，反转)
14. task_point_A (关节)
15. Home (关节)

总计: 15 步
```

## 四、左放/右放规则

| material_id | 方向 | 说明 |
|-------------|------|------|
| 奇数 (1,3,5) | 右放 (R) | 使用右侧物料点配置 |
| 偶数 (2,4,6) | 左放 (L) | 使用左侧物料点配置 |

### 6.2 BaseExecutor 接口设计

```cpp
class BaseExecutor {
public:
  bool init();                                    // 初始化滑轨电机
  bool moveToPosition(double target_pos);         // 移动到指定位置
  bool moveToTaskArea();                          // 移动到任务区
  bool moveToMaterialArea(const std::string &side, int position_id);  // 移动到物料区
  double getCurrentPosition();                    // 获取当前位置
  void stop();                                    // 紧急停止

private:
  rclcpp::Node::SharedPtr node_;
  // 伺服电机通信接口 (串口/CAN/ROS2 topic)
};
```

### 6.3 ActionType 扩展

```cpp
enum class ActionType {
  Home,           // 机械臂回零
  MoveTo,         // 关节空间运动
  MovePath,       // 关节路径运动
  MoveCartesian,  // 笛卡尔直线运动
  MoveBase        // 底盘移动 (新增)
};
```

### 6.4 Step 结构体扩展

```cpp
struct Step {
  ActionType action;
  std::vector<double> target;                      // MoveTo 使用
  std::vector<std::vector<double>> waypoints;      // MovePath 使用
  std::vector<geometry_msgs::msg::Pose> cartesian_waypoints;  // MoveCartesian 使用
  BaseTarget base_target;                          // MoveBase 使用 (新增)
};

struct BaseTarget {
  enum class Type { TaskArea, MaterialArea } type;
  std::string side;           // "left" 或 "right" (MaterialArea 时)
  int position_id;            // 位置编号 1,2,3 (MaterialArea 时)
};
```

## 八、底盘控制方案

### 8.1 通信方式

推荐使用 **ROS2 Topic** 控制伺服电机：

```
# 底盘控制话题
/base_controller/cmd_pos    # geometry_msgs/Point (目标位置)
/base_controller/pos        # sensor_msgs/JointState (当前位置反馈)
/base_controller/enable     # std_msgs/Bool (使能)
/base_controller/stop       # std_msgs/Empty (急停)
```

### 8.2 底盘节点

```
base_controller_node:
  - 订阅 /base_controller/cmd_pos
  - 发布 /base_controller/pos
  - 控制伺服电机 (串口/CAN)
  - 限位保护
  - 到位反馈
```

## 十、启动命令

```bash
# 启动完整系统
ros2 launch bringup full_system_bringup.launch.py

# 仅启动底盘仿真
ros2 launch bringup base_sim.launch.py

# 发送放任务 (物料1, 位置1)
ros2 service call /execute_task robot_interfaces/srv/ExecuteTask \
  "{task: {task_type: 1, material_id: 1, material_position_id: 1, task_id: 'test_001'}}"
```

## 十一、调试命令

```bash
# 查看底盘位置
ros2 topic echo /base_controller/pos --once

# 手动控制底盘

# 急停
ros2 topic pub /base_controller/stop std_msgs/Empty
```
