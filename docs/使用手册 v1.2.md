1. 通讯

确定您的 Teensy 4.1 和 Arduino Nano 正在通信的通信端口，您可以使用 Windows 设 备管理器找到这个，或者您可以打开 Arduino 软件并单击工具菜单，然后单击端口。在设 备的“端口号”输入字段中输入此值，然后单击“设置端口”。您只需执行一次此操作，因为软 件会在您下次打开它时记住哪个 COM 端口。
2. 速度/加速/减速

机器人速度设置为最大速度的百分比。如果您将速度设置为 100，这将是机器人 可以移动的最快速度。 低速的典型速度在 10% 到 25% 之间。加速和减速设置各有 2 个参数：持续时间和 百分比。持续时间是您希望机器人加速或减速的移动百分比，例如，如果您有一个 100 毫米长的移动，并且您希望机器人仅在前 5 毫米（或移动的 5%）内快速加速您可 以将 Dur 设置设置为 5，然后如果您希望机器人在最后 25 毫米（或移动的 25%）内更 缓慢地停止，您可以将减速持续时间设置设置为 25。第二个值是百分比是幅度的度 量，例如，如果您将“速度 %”设置为 10%，无论速度设置是什么，它都会在 10% 内加 速或减速。

4.编程

a.设置位置 始终在程序窗口中选择要放置下一个移动或指令的行。从移动类型下拉按 钮中选择您要插入的移动类型，然后按“Teach New Position”按钮将位置插入到

您的程序中。所有移动都将应用您为移动设置的速度、加速度和减速度设置. 位 置移动类型如下：

- Move J -移动 J 是一个关节移动，所有关节共同完成移动，这不一定是一条直 线，而是所有关节共同工作的扫掠运动。这是最简单和最常用的动作。

- OFFS J - 这是一个由存储位置的值偏移的关节移动。此移动将应用您在 “Teach New Position”按钮正上方的存储位置字段中设置的任何存储位置编 号。（存储的位置在下面的移动 SP 条目中有更详细的解释）。 -

- MoveL-Move L 是一个线性移动，这将执行一条完美的直线到你教的位置。 这个程序必须向 Arduino 发送一系列形成这条线的路点，在任何 Move L 之前 有几秒钟的延迟所有航路点都在传输。 -

- Move A - 移动 A 是弧形移动。您必须教 3 个点才能形成圆弧。首先选择“Move A beg”并教导弧的起点 - 第一个点的速度和方向值将应用于整个弧移动。其次， 您需要教授弧上的任何中点 - 选择“Move A Mid”并教授第二个点。最后选择 “Move A End”并在终点或圆弧处教您想要的点。您的命令窗口现在将为 3 个点中 的每一个点排成 3 行代码。当“Move A Beg”一行代码被执行时，程序会自动运行 接下来的两行代码来计算弧度。如果这些乱序，移动将无法工作。在移动 A 之前 有几秒钟的延迟将在形成弧的所有航路点传输到 Arduino 时执行。

MoveC - 移动 C 是一个圆形移动。你必须教 3 个点才能形成一个圆圈。首先选择“移 动 C 中心”并教导圆的中心点 - 第一个点的速度和方向值将应用于整个圆的移动。其 次，您需要在希望机器人开始和结束圆的圆周上示教起点 - 选择“Move C Start”并示 教第二点。最后选择“Move C Plane”并在您想要圆的同一平面上的任何位置教一个 点，该点仅用于知道您希望圆走哪个方向，这第三个点定义了平面 - 换句话说，只是 教另一个圆周上的点 它在哪里并不重要，它不是一个执行点，并且仅用于计算. 您的命令窗口现在 将为 3 个点中的每一个点排成 3 行代码。当执行“Move C Start”这行代码时，程 序将自动运行接下来的两行代码来计算圆。如果这些代码出现故障，则移动将 无法工作。在 Move C 之前有几秒钟的延迟将在形成弧的所有航路点传输到

Arduino 时执行。
- Move SP - SP 代表存储位置。在寄存器选项卡中，您可以设置 16 个存储位置。您可 以为以后要执行的任何位置或程序中的多个位置设置或保存 X、Y、Z、Y、P、R。当 您示教 Move SP 时，机器人将移动到您为注册选项卡上存储的位置输入的位置。*存 储的位置也可用于偏移 - 例如，如果您希望机器人进入您的零件上方，您可能需要使 用沿 Z 方向向上 25 毫米的存储位置进行偏移移动 - 例如：(0,0,- 25,0,0,0)。

- OFFS SP -这会将机器人移动到一个存储位置，然后将该位置偏移另一个存储位置 的值。这对于按行堆叠和放置零件很有用。此移动将使用“Teach New Position”按钮 正上方的存储位置字段中的值来执行主要移动，然后对于将被它偏移的存储位置，它 会自动选择下一个存储位置 - 但您可以使用手动输入字段来编辑移动将偏移的存储位 置（请参阅下面的编辑部分）。

- Teach SP - 此移动命令将在您的程序中插入 6 行，执行时会将机器人当前位置 存储到您选择的存储位置寄存器中。这使得根据需要填充存储位置变得更加容 易。

存储位置按钮将允许您输入代码行，将 X、Y、Z、Y、P、R 的各个元素设置在存储位 置中。 修改位置按钮仅与 Move J 一起使用，允许您修改程序中当前突出显示的 Move J 行。 删除按钮允许您删除当前选择的任何代码行。

b. 暂停
- 等待时间按钮插入一行，该行将暂停程序输入的时间量（以秒为单位）。
- 等待输入按钮将等待在输入字段中输入的 Arduino 输入出现，然后再继 续执行程序。这可以用作使机器人在继续之前等待其他事情发生的一种方式，或者 可以将其放置在程序的开头作为一种具有自动启动信号的方式。 等待输入关闭按钮将等待在输入字段中输入的 Arduino 输入关闭，然后再继续执行程 序。

c. IO 设置输出打开或设置输出关闭按钮允许您插入一行代码来打开或关闭您选择的

Arduino IO（有关 Arduino nano 上可用 IO 引脚的信息，请参阅输入输出选项卡底 部）。例如，如果您有一个气动夹具，您将按照线束手册连接您的螺线管以输出 Arduino 引脚 #14 并输入一行代码“Out On = 14”来控制您的夹具。

d. 导航 您可以根据需要创建任意数量的程序例程。在程序字段中输入您要创建的程序的 名称，然后按“加载程序”，如果该程序尚不存在，则将创建该程序，如果您已经创建了 该名称的程序，则将加载该程序。程序在您的 AR3 软件文件夹中创建，如果不再需 要，可以从该文件位置删除。
- “调用程序”按钮允许您插入一行调用程序的代码。 “返回”按钮插入一行代码，允许被调用的程序返回到它来自的程序。*注意你 不能从已经被调用的程序中调用另一个程序，你必须在调用另一个程序之前返回 到主程序。例如，您可能希望从该程序创建一个名为“Main”的程序，您可能会在 拾取部分的末尾调用一个名为“Pickup Part”的程序，您需要插入一个“Return”行以 返回到“ Main”程序，然后你就可以做其他事情或调用其他程序。您不能从“Pickup Part”调用另一个程序，您必须首先返回主程序。 “创建选项卡”按钮允许您在您的,您可以根据条件跳转或导航到的程序。*请注意， 您不能有 2 个具有相同编号的选项卡 - 每个选项卡都需要一个新编号。此功能与基本 编程非常相似。 “跳转到选项卡”按钮允许您跳转到一个选项卡，例如，您可以将“Tab 1”放在程序 的顶部，在底部放置一个“跳转到选项卡 1”，然后您的程序将无限循环。 “If Register Jump”按钮允许您根据寄存器的条件跳转到选项卡。例如，您可以有一个如 前所述的循环程序，然后在程序中添加一行以增加寄存器，然后在“跳转到选项卡 1”之前添 加一行，表示“如果寄存器 1 = 5 跳转到选项卡 2”和然后在“跳转到选项卡 1”之后的最底部放 置一个“选项卡 2”，以便程序运行 5 次，然后跳转到选项卡 2 并停止。

e. 寄存器 “Register”按钮允许您将寄存器设置为静态值，或者您可以在数字前添加 “++”，然后寄存器将增加数量。例如，如果您只输入“1”，它将始终将该寄存器的 值设置为 1，但如果您输入“++1”，则每次运行该行时该寄存器都会增加 1，以便 您可以使用这是为了计数。您可以输入任何数字，例如您可以输入“++3”并根据需 要按 3 计数。倒计时或递减也是如此 - 只需在数字前放置一个“--”。

f. 编辑代码行 您可以在命令窗口中选择一行代码，然后按“获取选择”按钮，这将将该行复制到手动输 入字段中。您现在可以在手动输入字段中编辑代码行，一些示例可能是：更改存储的位置 编号、更改位置、更改机器人速度或加速度。现在，使用您编辑过的代码行，您可以在命 令窗口中重新选择原始代码行，然后按“替换”按钮，旧代码行将被新的编辑行替换。“插入” 按钮会将手动输入字段中的测试插入到您的程序中而无需替换 - 您可以使用它来使用插入按 钮插入注释或手写代码行。

4. 校准（主要使用单独校准和自动校准，其他功能介绍）

a. 强制校准 此按钮允许您强制在每个轴的中点进行校准。这仅在设置您的机器人时使用 - 例 如，如果您的机器人尚未校准，并且您正在尝试旋转关节并且您达到轴限制，则此按 钮将允许您在自动执行之前执行您需要执行的操作校准你的机器人。

仅在构建和设置期间使用此按钮。

b. 精细校准 此功能允许您设置参考位置，以便您可以检查在出现弯曲限位开关或必须 更换机器人部件的情况下校准的真实性。例如，您可以将机器人点动到您知道 的某个参考位置，也许机器人拿着一个指针并转到一个已知位置，然后您可以 按“teach Fine校准位置”来保存该位置。稍后您可以按“转到精校准位置”返回原 始示教位置并检查精度。如果熄灭，您可以小步将机器人点动到正确的校准位 置，然后按“执行精校准”，您的校准将调整到原始参考位置。

c. 方向默认值（一般不要动）

校准默认设置在安装限位开关的轴的一侧。例如，如果您正在构建自己的自定 义机器人，您可以更改这些值以将机器人驱动每个轴的方向更改为校准限位开关。 有 6 个值 - 每个关节一个，对于负方向或正方向，它们只能是“0”或“1”。

电机方向输出以相同的方式工作，如果您正在构建自定义机器人并且您的机械 师需要电机以另一种方式旋转，则允许您将电机驱动方向从顺时针更改为逆时针。 同样，有 6 个值 - 每个关节一个，它们只能是负方向或正方向的“0”或“1”。

d. 机器人校准值 校准值允许您输入每个关节的运动自由度以及使该行程发生的步进电机 步数。 如果构建您自己的自定义机器人，您可以更改这些值以匹配您的自定义 运动范围和步进传动装置。

## 概述
+ **ar3_control**
+ 通过 MoveIt 用户界面控制手臂
+ 提供移动组界面的演示

+ **ar3_description**
+ 机械臂硬件描述、urdf等的说明

+ **ar3_hardware_interface**
+ 用于硬件驱动程序的 ROS 接口，建立在 ros_control 框架上
+ 管理关节偏移、限制和关节和执行器消息之间的转换

+ **ar3_hardware_drivers**
+ 处理与电机控制器的通信

+ **ar3_microcontrollers**
+ 用于电机控制器的固件，即:teensy4.1

+ **ar3_moveit_config**
+ 用于运动规划的 MoveIt 模块
+ 通过 Rviz 控制手臂

+ **ar3_gazebo**
+ Gazebo 上的模拟

### 使用 RViz 中的 MoveIt 控制真实世界的手臂

* 启动`ar3_hardware_interface` 模块，它将加载配置和机器人描述 ``` roslaunch ar3_hardware_interface ar3_hardware_bringup.launch use_existing_calibrations:=true ``` 硬件接口还将启动硬件驱动程序并初始化与teensy的通信。您在启动节点时使用 `use_existing_calibrations` 参数跳过联合编码器校准序列
