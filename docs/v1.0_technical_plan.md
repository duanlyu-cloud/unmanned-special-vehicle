# AR4 ROS2 v1.0 技术方案

## 一、系统架构

```
task_manager_node (入口)
    ↓
TaskManager (服务层) ←→ ROS2 Service (/execute_task, /reset_state)
    ↓
MissionScheduler (调度层) → Step 序列构建 + 执行
    ↓
RobotExecutor (执行层) → MoveGroupInterface 封装
    ↑
MaterialManager (数据层) ← YAML 配置
```

## 二、任务类型

| 类型 | 名称 | 流程 |
|------|------|------|
| task_type=1 | 放任务 | 任务点 → 物料点 |
| task_type=2 | 取任务 | 物料点 → 任务点（镜像） |

## 三、动作流程设计

### Task 1 — 放任务

```
任务区 (6步):
1. Home (关节)
2. task_point_A (关节)
3. task_cartesian_path_forward (笛卡尔直线: A → task_pose)
4. task_cartesian_path_reverse (笛卡尔直线: task_pose → B)
5. task_point_B (关节)
6. Home (关节)

物料区 (6步，material_id 决定左右):
7. Home (关节)
8. na (关节，forward_points[0])
9. material_cartesian_path_forward (笛卡尔直线: na → material_pose)
10. material_cartesian_path_reverse (笛卡尔直线: material_pose → nc)
11. nc (关节，return_point)
12. Home (关节)

总计: 12 步
```

### Task 2 — 取任务（与 Task 1 完全镜像）

```
物料区 (6步):
1. Home (关节)
2. nc (关节，return_point)
3. material_cartesian_path_reverse反向 (笛卡尔直线: nc → material_pose)
4. material_cartesian_path_forward反向 (笛卡尔直线: material_pose → na)
5. na (关节，forward_points[0])
6. Home (关节)

任务区 (6步):
7. Home (关节)
8. task_point_B (关节)
9. task_cartesian_path_reverse反向 (笛卡尔直线: B → task_pose)
10. task_cartesian_path_forward反向 (笛卡尔直线: task_pose → A)
11. task_point_A (关节)
12. Home (关节)

总计: 12 步
```

## 四、配置文件结构

### poses.yaml

```yaml
# 基础位姿
home_pose:
  joints: [j1, j2, j3, j4, j5, j6]

task_point_A: [j1, j2, j3, j4, j5, j6]
task_point_B: [j1, j2, j3, j4, j5, j6]

task_pose:
  joints: [j1, j2, j3, j4, j5, j6]

task_cartesian_path_forward:   # A → task_pose
  - {x, y, z, qx, qy, qz, qw}

task_cartesian_path_reverse:   # task_pose → B
  - {x, y, z, qx, qy, qz, qw}

# 物料配置
materials:
  material1:
    name: "Material A"
    material_pose: [j1, j2, j3, j4, j5, j6]
    forward_points:           # na, nb, ... (从远到近)
      - [j1, j2, j3, j4, j5, j6]
    return_point: [j1, j2, j3, j4, j5, j6]  # nc
    material_cartesian_path_forward:   # nb → material_pose
      - {x, y, z, qx, qy, qz, qw}
    material_cartesian_path_reverse:   # material_pose → nc
      - {x, y, z, qx, qy, qz, qw}
```

## 五、服务接口

| 服务 | 类型 | 说明 |
|------|------|------|
| `/execute_task` | `robot_interfaces/srv/ExecuteTask` | 发送任务 |
| `/reset_state` | `std_srvs/srv/Trigger` | 重置状态（Error → Idle） |
| `/task_result` | `robot_interfaces/msg/TaskResult` | 任务结果话题 |

### ExecuteTask.srv

```
robot_interfaces/Task task
---
bool accepted
string message
```

### Task.msg

```
uint8 task_type
uint8 material_id
string task_id
```

### TaskResult.msg

```
string task_id
uint8 result_code   # 0=成功, 1=物料未找到, 2=未知任务类型, 3=执行失败
string message
```

## 九、已知问题与解决方案

| 问题 | 解决方案 |
|------|----------|
| 笛卡尔路径速度不一致 | 使用 setMaxVelocityScalingFactor(0.5) 统一 |
| KDL 求解器超时 | 超时设置 ≥50ms |
| 关节状态过时 | waitForFreshJointState 等待新数据 |
| joint_state_broadcaster QoS | 使用 TRANSIENT_LOCAL |
